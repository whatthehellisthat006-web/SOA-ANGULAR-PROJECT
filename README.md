# Koussay Airline Frontend

Standalone Angular frontend for the Koussay Airline Spring Boot project.

## Start

Install dependencies with `npm install`, then run `npm start`. The frontend is served at `http://localhost:4200` and expects the Spring application at `http://localhost:8081/Vol`.

## Demo accounts

- Administrator: `admin` / `123`
- User: `aziz` / `123`

The demo login and roles are stored in the frontend, following the reference project.
